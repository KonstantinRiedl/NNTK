# NNTK code

## Files

- `config.py`: experiment configuration
- `data.py`: synthetic target and seed control
- `model.py`: network, loss, tensor helpers
- `linear_algebra.py`: HVP/GNVP, CG, preconditioners
- `ntk.py`: NTK Gram/eigensystem/projections
- `optimizers.py`: custom optimizers and factory
- `training.py`: training loop, tuning, aggregation
- `plotting.py`: plotting helpers
- `run_experiment.py`: full driver script
